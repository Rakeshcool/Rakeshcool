## 🚀 What I'm Working On

### Local AI & LLM Infrastructure
Running and optimizing local language models using **llama.cpp**, including GPU acceleration, KV-cache tuning, quantized GGUF models, embedding servers, and OpenAI-compatible endpoints.

### Retrieval-Augmented Generation
Designing RAG pipelines for long-form content such as **podcast and video transcripts**, with a focus on chunking, retrieval quality, context management, and reducing hallucinations.

### AI Video & Audio Processing
Building workflows that combine **speech-to-text, embeddings, retrieval, and local LLM summarization** for processing videos and podcasts.

### AI Agents, MCP & Automation
Exploring **MCP servers, tool-connected AI systems, n8n-style automation, and local agents** that can interact with external applications and services.

### AI Developer Tools
Building lightweight tools around AI workflows, including **local Markdown viewers, model-server orchestration, and desktop/browser-based utilities**.
